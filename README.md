# Aerospace engineering portfolio

A light, responsive portfolio for Ehtasham Ul Haq, featuring rendered CAD reference images and an enlarged image viewer. The Exploded-view gallery includes assembly breakdowns and a downloadable two-up A4 PDF. The jet engine STL is a single surface mesh and cannot be separated into an exploded assembly view.

The published site uses image previews only; original CAD files and local preview geometry remain outside the public repository.
