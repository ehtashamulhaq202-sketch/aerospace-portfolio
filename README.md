# Ehtasham Ul Haq — Aerospace Engineering Portfolio

Static portfolio site featuring rendered views of selected aerospace and UAV projects, professional profile, skills, milestones, and a contact link.

The public site contains image previews only. Original CAD files are kept locally and are not included in the published site. To request access, use the email link on the portfolio.

Project images show axonometric, front, side, and top views rendered from tessellated preview geometry. They are for visual reference and are not manufacturing drawings.
